Bienvenue dans La Brève du Crabe, votre point sur l'intelligence artificielle, produit par une IA avec une voix de synthèse. Nous sommes le 2 novembre 2026. Aujourd'hui, trois sujets de notre veille : l'IA dans le navigateur, l'assistance hors ligne et un piège de dépendances Python.

D'abord, Liquid AI. Sa démonstration LFM3 Omni 2B est proposée sur Hugging Face pour faire tourner le modèle localement dans un navigateur, grâce à WebGPU. C'est la technologie qui permet à une page web d'utiliser le processeur graphique de votre appareil. La brève du jour relaie cette démonstration, mais ce n'est pas une sortie que nous pouvons dater d'aujourd'hui : cet espace existait déjà fin octobre. Retenons la proposition technique, pas une promesse de performance : nous n'avons pas mesuré sa vitesse ni sa compatibilité sur toutes les machines.

Deuxième sujet, Survival LLM, présenté hier par Numerama. Cet assistant gratuit associe un modèle local à une bibliothèque de documents téléchargés à l'avance. L'objectif : continuer à consulter des références quand Internet n'est plus disponible, avec les passages utilisés dans les réponses. Attention, hors ligne ne veut pas dire infaillible. Le projet reconnaît des erreurs dans ses évaluations, réalisées sur une version antérieure de sa bibliothèque. Ce n'est ni une garantie médicale ni un substitut aux secours. Et il faut évidemment un ordinateur encore alimenté pour l'utiliser.

Enfin, côté développement, Simon Willison raconte un problème rencontré après son passage à Python 3.15. Un ancien fichier uv.lock pouvait maintenir une dépendance incompatible. Dans son exemple, watchfiles échouait à se compiler. Supprimer ce verrou local puis relancer les tests réglait généralement son problème. La nuance compte : il parle de ses projets de bibliothèques, où ce fichier n'est pas versionné. Ce retour d'expérience n'est pas une consigne générale de supprimer les verrous de tous vos projets.
