Questions fréquentes

Tout ce qu'on nous demande

C'est quoi le rapport avec Nous Research ?
Hermes Agent est développé par Nous Research. Nous ne sommes pas eux : on est une communauté francophone qui traduit leur méthode en un guide simple, gratuit, testé. On crédite et on renvoie systématiquement vers la documentation officielle.
Ça coûte combien, au total ?
Le logiciel : 0 € (open source). Ensuite, tu payes seulement le modèle que tu branches — par exemple DeepSeek coûte quelques centimes par jour pour un usage normal. Le guide explique comment choisir pour quelques euros par mois.
Je dois savoir coder ?
Pour installer : non, le guide est pas-à-pas. Pour aller loin : savoir demander les bonnes choses suffit pour commencer. Hermes est justement fait pour exécuter le technique à ta place.
Je peux le faire tourner 24 h/24 ?
Oui : un petit VPS (dès ~5 €/mois) le fait tourner en continu, même ordinateur éteint. Pas encore d'hébergeur ? Hostinger — lien partenaire qui finance ce site (rabais inclus).
Et OpenClaw, c'est pareil ?
Non, les deux sont complémentaires : le kit OpenClaw installe l'assistant personnel open source sur ta machine. Beaucoup installent les deux — le kit OpenClaw + le kit Hermes Agent.
