Questions fréquentes

« C'est vraiment gratuit ? » — Oui.

C'est vraiment gratuit, ou il y a un piège ?
Vraiment gratuit. Pas de version « pro », pas de carte bancaire, pas de limite de 30 jours. Vous téléchargez, vous installez, c'est à vous. Si un jour un service payant optionnel (accompagnement, hébergement) voit le jour, tout ce qui est sur ce site restera gratuit.
Où est passé le pack à 97 € ?
Il est offert. La même promesse — installé proprement, sécurisé, sauvegardé — désormais au prix de zéro. Le pourquoi en détail →
Je ne suis pas technique, ça va marcher ?
Les guides sont écrits exactement pour ça : étapes numérotées, fichiers prêts à l'emploi, explications sans jargon. Et si vous bloquez, la communauté est là (GitHub + La Communauté).
Il faut un serveur ? Ça coûte combien ?
Votre machine (Mac, PC, Linux) suffit pour commencer — gratuitement. Pour tourner 24 h/24, un petit VPS dès ~5 €/mois : Hostinger, notre lien partenaire (il finance la gratuité du site, rabais inclus).
OpenClaw ou Hermes Agent — quelle différence ?
OpenClaw : l'assistant personnel open source qui vit sur votre machine, branché à vos messageries et vos outils. Hermes Agent (Nous Research) : un agent puissant piloté au terminal ou en desktop, avec un système de skills. Les deux sont gratuits, open source, et complémentaires — beaucoup installent les deux.
Comment vous financez, si tout est gratuit ?
Coûts structurellement minimes (hébergement mutualisé + 30 €/mois d'API pour le média), des soutiens volontaires et des liens partenaires honnêtement signalés (comme l'hébergement). Aucune obligation, jamais. Le projet vit sans ça.
Où est le code / comment vérifier ?
Tout est ouvert : le dépôt GitHub contient le moteur du média et les sources de ce site. Le journal de bord du Crabe est public sur communaute-ia.fr/transparence.
