2. Données collectées

Dans le cadre de l'utilisation de notre site et de l'achat de nos produits, nous sommes susceptibles de collecter les catégories de données suivantes :

2.1. Données collectées lors du paiement

  • Adresse email : collectée via la plateforme de paiement sécurisée Qonto
  • Informations de transaction : montant payé, date et heure de la transaction, identifiant de transaction
  • Informations de facturation : nom, prénom (si fournis via Qonto)

Note : Nous ne collectons ni ne stockons vos données bancaires. Le paiement est entièrement géré par Qonto, un prestataire de services de paiement agréé et sécurisé.

2.2. Données de navigation

  • Données de connexion : adresse IP, type de navigateur, pages consultées, date et heure de visite
  • Cookies analytiques : si vous acceptez les cookies, nous pouvons utiliser des outils d'analyse de trafic (type Google Analytics) pour améliorer notre site

2.3. Données de support client

  • Communications : lorsque vous contactez notre support (téléphone, email), nous conservons un historique de vos demandes pour améliorer notre service

3. Finalités du traitement

Vos données personnelles sont collectées et traitées pour les finalités suivantes :

  • Exécution du contrat : livraison du pack d'installation OpenClaw par email, traitement de votre commande
  • Support client : répondre à vos questions, vous aider lors de l'installation
  • Obligations légales : conformité aux obligations comptables et fiscales (conservation des factures)
  • Amélioration du service : analyse statistique du trafic pour améliorer l'expérience utilisateur
  • Communication commerciale : uniquement si vous avez donné votre consentement explicite, nous pouvons vous envoyer des informations sur nos nouveaux produits ou services

4. Base légale du traitement

Conformément au Règlement Général sur la Protection des Données (RGPD), nos traitements reposent sur les bases légales suivantes :

  • Exécution du contrat (article 6.1.b du RGPD) : pour la livraison du produit acheté
  • Obligation légale (article 6.1.c du RGPD) : pour la conservation des données de facturation
  • Intérêt légitime (article 6.1.f du RGPD) : pour l'amélioration de nos services et la sécurité du site
  • Consentement (article 6.1.a du RGPD) : pour les communications marketing (si vous avez accepté)

5. Destinataires des données

Vos données personnelles peuvent être transmises aux catégories de destinataires suivants :

  • Personnel de BLOCKOS : nos équipes internes pour le traitement des commandes et le support client
  • Prestataires de services :
    • Qonto : pour le traitement sécurisé des paiements
    • Cloudflare : pour l'hébergement du site web
    • Outils d'analyse (si applicable) : pour l'analyse du trafic
  • Autorités légales : si la loi l'exige ou pour protéger nos droits

Aucune revente de vos données : Nous ne vendons, ne louons et ne partageons jamais vos données personnelles à des tiers à des fins commerciales.

6. Durée de conservation

Vos données sont conservées pendant les durées suivantes :

  • Données de transaction : 10 ans (obligations comptables et fiscales)
  • Données de support : 3 ans après la dernière interaction
  • Données de navigation : 13 mois maximum (cookies analytiques)
  • Données marketing : jusqu'à votre désabonnement ou 3 ans d'inactivité

7. Vos droits (RGPD)

Conformément au RGPD, vous disposez des droits suivants concernant vos données personnelles :

  • Droit d'accès (article 15) : obtenir une copie de vos données
  • Droit de rectification (article 16) : corriger des données inexactes
  • Droit à l'effacement (article 17) : demander la suppression de vos données (sous réserve des obligations légales)
  • Droit à la limitation (article 18) : limiter le traitement de vos données
  • Droit à la portabilité (article 20) : recevoir vos données dans un format structuré
  • Droit d'opposition (article 21) : vous opposer au traitement de vos données (notamment pour le marketing)
  • Droit de retirer votre consentement : à tout moment pour les traitements basés sur le consentement

9. Sécurité des données

Nous mettons en œuvre des mesures techniques et organisationnelles appropriées pour protéger vos données contre tout accès non autorisé, modification, divulgation ou destruction :

  • Chiffrement SSL/TLS pour toutes les communications
  • Accès restreint aux données personnelles (uniquement le personnel autorisé)
  • Sauvegardes régulières et sécurisées
  • Surveillance et mise à jour des systèmes de sécurité

10. Cookies

Notre site utilise des cookies pour améliorer votre expérience de navigation. Vous pouvez à tout moment modifier vos préférences de cookies dans les paramètres de votre navigateur.

Pour plus d'informations sur les cookies utilisés, vous pouvez nous contacter à l'adresse : support@openclaw-france.fr
